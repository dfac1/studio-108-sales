# Booking Rules — Правила записи

## Что НЕ предлагать клиентам
- Любые слоты с «Аренда»
- Любые «Индивидуальное занятие»

Это внутренние слоты, не для первичной продажи пробного занятия.

## Логика записи
1. Уточнить цель/направление и возраст.
2. Подобрать 2-3 групповых варианта.
3. Получить подтверждение клиента.
4. Зафиксировать в CRM/таблице.
5. Отправить подтверждение клиенту.

## Переносы и пропуски
- Пробные занятия переносить можно.
- Менеджер должен приоритетно удерживать клиента на изначально выбранной дате/времени.
- Перенос занятий по абонементу возможен только по болезни и только при наличии справки от врача.
- Правило по болезни действует и для детей, и для взрослых.
- Во всех остальных случаях пропущенные занятия сгорают.

## Заморозка
- Заморозка абонемента доступна на любой срок.
- Лимит: не более 2 раз в год.

## Приоритет по данным
1. `changes-log.md` (самое свежее)
2. `schedule.md`
3. `offers.md`
4. Уточнение у администратора
